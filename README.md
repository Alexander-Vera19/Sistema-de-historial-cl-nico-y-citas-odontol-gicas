# Sistema de Historial Clínico y Citas Odontológicas

## Descripción
Plataforma web para digitalizar archivos físicos y optimizar el control de 
turnos de la clínica. El sistema garantiza una experiencia fluida tanto en 
computadoras como en teléfonos móviles.

## Tecnologías utilizadas
- HTML5 Semántico
- CSS3
- JavaScript ES6 nativo (lógica de autenticación de roles y validaciones 
  de seguridad)

## Funcionalidades principales
- Inicio de sesión con selección de rol (paciente, odontólogo, 
  administrador)
- Agendamiento de citas médicas
- Registro y consulta de historial clínico
- Panel de reportes y control de seguridad para administrador

## Instrucciones de ejecución
Hacer clic directamente en el enlace de GitHub Pages para abrir la 
aplicación web desde cualquier celular o computadora:
